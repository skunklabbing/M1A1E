# M1A1 Extended
Adds a variety of addons to ATLAS' M1A1 mod
## Features
### Armor
- Side Composite Armor, 3 layers of effective armor
- Cheek Applique, 2 layers of effective armor

### Systems
- Trophy Hard-kill System
- Enhanced Systems, SEPv4

## Ammo
- M829A4 APFSDS-T, 825mm RHA Penetration

## Installation
1. Install the latest release
2. Copy its contents and replace
3. Play the game
